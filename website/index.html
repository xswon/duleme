Local-first RSS Reader

把真正想看的内容，放在一个安静的地方。

读了么是一个本地优先的 RSS 阅读器。订阅、阅读、收藏、笔记和播客集中在一个应用里，AI 与转录按需开启，不影响基础阅读体验。

下载 macOS 版 查看 GitHub
V0.1 · macOS 优先 · Windows 版本后续提供

安装就能开始

使用读了么精选、导入 OPML，或者从空白开始。无需 Node、Docker 或命令行。

数据留在本地

订阅、文章状态、收藏、笔记和播放进度默认保存在本机，并支持备份与恢复。

增强能力可选

需要时再配置自己的 AI 或转录服务。不配置 API，也是一套完整的 RSS 阅读器。

Local-first，不先要一个账号。

V1 不要求注册、登录或云同步。先把阅读这件事做好；当你需要 AI、播客转录或其他增强功能时，再自行开启。
