# 原型到生产版实施记录

2026-09-15：用户确认以昨晚更新后的 `docs/prototypes/netnewswire-ui/index.html`、`styles.css`、`prototype.js` 为唯一视觉基准；旧预览 PNG 与旧设计文档发生冲突时不采用旧值。

## 已确认约束

- 逐项复用字体、字号、字重、行高、字距、颜色、图标路径与描边、尺寸、内外边距、间距、圆角、背景、边框和阴影。
- 原型的评审控制条、外框与静态假数据不进入生产界面。真实业务、存储、路由、单一音频控制器继续复用。
- 不自行设计缺失状态；视觉冲突或未知状态须由用户确认后实施。
- 当前原型最终值：桌面列表标题 13.5px / 650 / 1.3，摘要 12px / 1.35，缩略图 40px；已读与未读保持相同视觉权重，仅未读显示小蓝点，已读来源不保留点位占位并与标题左对齐。
- 左栏时间线、收藏、音频、笔记、搜索为连续一级导航，无“工具”标题或额外留白；文件夹默认 400 字重，选中时蓝色 700。
- 详情副标题来源与时间戳统一为 13px 灰色 400；左栏刷新和详情 Tab 图标以 15px 可见尺寸为基准，逐字稿使用标准 Lucide `AudioLines`。
- 音频与笔记数量只显示在中栏顶栏标题后，垃圾桶负责删除全部并确认；搜索页不显示批量已读和排序。
- 最终 CSS 的常驻侧栏断点为 1040px，常规列宽 228px + 342px；收起为 52px + 360px。900–1039px 为 330px 列表与详情。
- 当前设置形态为居中弹窗；阅读详情操作使用顶部横向 `reader-actions`，播放器统一复用 `player-*` 控件。

## 分工与状态

1. 主代理：导航、时间线、移动底栏、公共样式、刷新反馈与整合验收。导航 Luna-High 首次启动因用量限制失败，未写入文件，由主代理接手。
2. Luna-High 阅读代理：详情、阅读设置、播放器、内容标签；主实现已整合。
3. Luna-High 工具代理：音频、搜索、笔记、设置；主实现已整合。

## 已确认例外与验收

- 添加订阅的完整界面没有独立原型；用户确认保留生产版既有样式。
- 用户确认采用昨晚更新后的顶部横向阅读操作栏，窄栏沿用同组尺寸、颜色与间距。
- 浏览器安全策略拒绝打开 file 原型，未绕过。用户随后提供桌面默认、收起侧栏和播放列表截图，作为视觉复核材料。
- 生产页可用浏览器读取实际尺寸和样式；完整同内容截图叠加、移动端参考图与全部状态验收仍待完成。
- 不将既有文档记载的历史测试通过视为本轮验证通过；最终结果另行记录。
