# 读了么 · NetNewsWire 风格 UI 原型

这是与生产 React 代码隔离的静态高保真原型，用于评审三栏信息架构、响应式导航、密度和阅读状态。品牌以“读了么”为准；生产实现复用真实数据和业务能力，不复制评审控制条或静态假数据。

## 文件与预览

- `index.html`：无需构建即可打开的原型入口。
- `styles.css`：三栏布局、工具页、抽屉、手机安全区和反馈层样式。
- `prototype.js`：状态切换、文章选中、工具页、文件夹命名、刷新失败分层、排序和全部已读演示。
- `previews/desktop-selected.png`、`desktop-empty.png`、`desktop-feed-selected.png`、`desktop-article-selected.png`：1440 × 900 桌面代表状态。
- `previews/desktop-sidebar-rail.png`：左侧边栏收起后保留 52px 可操作细条的桌面状态。
- `previews/desktop-reading-settings.png`：阅读字号、行距、版心和主题设置浮层，自右栏顶栏胶囊下方展开。
- `previews/desktop-playlist.png`、`desktop-search.png`：1440 × 900 音频和搜索工具页代表预览（文件名保留内部 `playlist` 状态名）。
- `previews/desktop-starred.png`：1440 × 900 收藏页，中栏只显示已收藏条目，顶栏清空按钮为 Eraser。
- `previews/desktop-clear-tooltip.png`：收藏页悬停清空按钮时的自绘提示，用于记录提示样式与位置。
- `previews/desktop-rail-hint.png`：52px 收起细条里悬停图标项时的自绘提示，用于记录「标签被隐藏后提示才出现」的规则。
- `previews/mobile.png`：390 × 840 手机单页、抽屉与底部导航代表预览。

用本地静态服务器打开：

```sh
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。也可以直接双击 `index.html`。

## 状态模型与实现约束

状态拆成互不混淆的维度：`scope`（`today`、`starred`、`feed`、`folder`）、时间线筛选（内容类型与仅看未读）、`detail`（`selected`、`empty`、`article`）和 `tool`（`playlist`、`notes`、`search`、`settings`）。未读是时间线筛选，不是独立 scope；收藏按文章逐条建模（行上的 `data-starred`），左栏与抽屉计数由已收藏条目数推导，收藏页只显示已收藏条目。文章切换只更新详情，不重置当前 scope；工具页保留左栏，并把列表放在中栏、选中项放在右栏；设置跨中栏和右栏。URL `?view=` 只作为评审状态入口，不代表真实路由。

桌面 ≥1040px 为三栏；900–1039px 隐藏常驻左栏，中栏顶栏左侧显示菜单按钮并用抽屉恢复完整导航；761–899px 为列表/详情单页，中栏顶栏保留菜单和详情返回；≤760px 使用 390px 手机预览，文章详情有返回、菜单和右侧文章操作。桌面、52px 收起细条和抽屉均把音频、笔记、搜索作为一级导航直接放在收藏之后、订阅树之前，不显示“工具”标题或分组留白。文件夹默认 400 字重，仅选中时蓝色加粗。所有文章/详情图标使用内联 Lucide 风格 SVG，不用字符图标。

时间线取消“今天 / 昨天”独立日期分组行（卡片内已带有相对时间戳），采用单卡约 68–72px 的高密度排版与 40 × 40 缩略图，大幅提高单屏信息密度与扫读效率；默认显示最近 30 个本地自然日，并提供“全部 / 文章 / 播客”与“仅看未读”筛选。左栏时间线数字固定表示最近 30 天未读，以 `99+` 封顶；中栏每次继续加载 30 天，加载后左栏数字口径不变。列表末尾只显示灰色常规字重的“继续加载 30 天”。已读与未读保持相同文字层级，仅未读项显示小蓝点；已读来源不保留蓝点占位，左移后与标题首字对齐。

桌面左栏收起后保留 52px 细条，继续提供时间线、收藏、音频、笔记、搜索和设置入口，这六项此时只剩图标，悬停会补回名字；再次点击顶部栏位按钮恢复完整边栏，提示随之撤下。“设置”使用独立底部锚点，在已选文章、空详情、订阅源、普通文章、音频、搜索和设置等状态中保持同一纵向坐标；订阅内容增长时向下延展，不把工具挤出默认首屏。

详情文章容器整体采用 9px 顶部起始轴，与左栏导航和中栏内容区对齐；标题、副标题、播放器、标签和正文共享同一左边界。副标题的来源与时间戳统一为 13px 灰色常规字重，来源不加粗。桌面文章快捷操作收纳在右栏顶栏内右侧的一枚横向胶囊里，自左至右为“标记已读、收藏、打开原文、阅读设置（Aa）、沉浸阅读”；顶栏位于各栏滚动容器之外，因此正文滚动时胶囊位置固定，且胶囊与正文之间不存在重叠路径。阅读设置面板从该顶栏下方展开，右边缘与胶囊对齐。761–899px 单页模式下右栏顶栏沿用同一枚胶囊，并隐藏中栏的时间线工具条。胶囊里的收藏按钮在两态间切换，与收藏页的清空动作共用同一份状态。打开原文按钮不提供复制链接功能；正文底部来源链接同样可打开原文。文章与播客的第一个 Tab 都统一为“正文”并共用正文图标；正文、AI 摘要、逐字稿、笔记的 Tab 图标统一为 15px 可见尺寸，逐字稿使用标准 Lucide `AudioLines` 六竖线。无缩略图直接进入正文，仅音频文章显示播放器。AI 摘要不显示“内容精华”标题，短精华直接展开；深度内容默认收起，由其下方居中的“展开深度精华”按钮控制。

播放控件只有一套规范：文章内播放器、音频页主播放器和队列行的播放键共用同一组原子样式（`.player-icon-btn`、`.player-toggle`、`.player-track`、`.player-times`、`.player-speed`），色值、图标尺寸（16px / 描边 1.8px）、进度条高度（5px）、时间字号（11px）完全一致，只允许按容器调整尺寸——列表页主钮 44px、文章内主钮 34px。主钮统一为 `--player-accent`（#3175c6）实心圆加浅阴影，倍速统一为 36 × 28 灰底胶囊，进度条统一为 5px 且 hover 只改变轨道底色（不再变高，避免列表页 hover 时布局抖动）。左右跳转槽位的语义随场景取最自然的一个：文章内是“后退 15 秒 / 快进 30 秒”（单集），音频页是“上一条 / 下一条”（队列）；倍速固定在该组右侧末位。三处的色值全部来自 `--player-*` 令牌，不再各自硬编码。

作用于“全部”的顶栏按钮只有一个槽位，按状态切换图标与悬停提示：音频页为 `Eraser` +「清空播放列表」，收藏页为 `Eraser` +「清空收藏」，笔记页为 `Trash2` +「删除全部笔记」。`Eraser` 表示可恢复的清空（节目可重新加入、文章可重新收藏），`Trash2` 只留给不可恢复的真删除，列表行内的单条移除同样使用 `Trash2`。这三处都不再做二次确认：悬停提示已经说明后果，可恢复的清空也能通过重新加入/重新收藏撤回，点击即执行并给出成功反馈。收藏页同时在右栏胶囊里提供逐篇收藏/取消收藏。

悬停提示由页面自己绘制，不再依赖 `title` 原生提示：原生提示由操作系统渲染，有约 1 秒延迟、无法改样式、**不会出现在任何截图里**，内嵌预览环境下还会被整体屏蔽——这正是「hover 时看不到提示」的原因。实现上把带 `title` 的控件统一迁移为 `data-tip`，由一个固定定位的单例 `.app-tooltip` 承载，位置在 JS 里计算并夹在视口内，因此滚动容器不会裁掉它。**有文字标签的控件一律不参与**：时间线、收藏、音频、笔记、搜索、设置，以及订阅树里的文件夹行与订阅源行，各自已经显示名字，提示只会把名字重复一遍——订阅树因此只写 `aria-label` 供读屏使用，不再写 `title`。文章行同样排除——宽列表行不该在鼠标扫过时弹浮层。**唯一的例外是 52px 收起细条**：细条把标签整体隐藏，那六枚只剩图标的按钮重新需要提示，所以绑定的是「标签是否可见」而不是控件类型——同一个按钮，展开时没有提示、收起时有提示，一次状态同步里自动增删。顶部栏那枚边栏开关两态都只有图标，提示随状态在「展开边栏 / 收起边栏」之间切换，由同一处逻辑写入，因此 `?sidebar=collapsed` 直接进入时也不会停留在静态的「收起边栏」。上述所有控件的 `aria-label` 可访问名称都保留，不受影响。新增或改名的提示只需写 `title`，状态同步时会自动迁移；若名字来自 `?test=long-name` 之类的覆盖，覆盖必须发生在标签捕获之前，否则提示会停留在旧名字上。

刷新反馈按层级处理：普通操作 toast 自动消失；刷新成功约 3.5 秒后消失；刷新失败持久显示直到关闭或重试成功，并提供分开的“查看”“重试”“关闭”动作。“查看”打开失败订阅源列表，可逐个重试。桌面反馈在右下角，手机在底部导航和 safe-area 上方。

“我的订阅”加号只打开添加菜单：添加订阅源明确复用 URL / OPML 流程提示；添加文件夹使用轻量命名弹窗，空名称、重名和包含“失败”的名称分别演示失败反馈，创建成功后立即插入订阅树，不跳转设置页。

## 评审入口与验证矩阵

- `?view=selected&clean=1`：默认桌面三栏和右侧文章操作。
- `?view=selected&sidebar=collapsed&clean=1`：收起主边栏，保留 52px 可操作细条。
- `?view=article&reader=open&clean=1`：在右栏顶栏胶囊下方展开阅读设置浮层。
- `?view=empty&clean=1`：空详情；右栏顶栏的文章操作胶囊完全隐藏，不显示禁用态（音频、搜索等无文章的工具页同样隐藏）。
- `?view=feed&clean=1`：具体订阅源、英文时间和自然末尾历史入口。
- `?view=article&clean=1`：普通文章、有封面、AI 摘要、无播放器。
- `?view=article&cover=none&clean=1`：无缩略图时正文直接开始。
- `?view=playlist&clean=1` / `?view=notes&clean=1` / `?view=search&clean=1` / `?view=settings&clean=1`：工具页的三栏映射。音频和笔记只在中栏顶栏显示一次“标题 N 条”，内容区直接进入列表或空状态；音频顶栏是 Eraser「清空播放列表」，笔记顶栏是 Trash2「删除全部笔记」，都不做二次确认。搜索页不显示批量已读和排序。音频播放器使用高于队列卡片的独立浅色卡片，队列按“52 × 52 封面—标题｜订阅源/剩余时间与时间戳—独立播放—删除”横向布局；播放按钮只播放/暂停，点击封面或标题才打开右栏文章，且同一时间只有一个节目播放。
- 左栏“收藏”：收藏页（`scope=starred`）只列出已收藏条目，顶栏是 Eraser「清空收藏」，点击后计数归零并显示“还没有收藏内容”空态；`previews/desktop-starred.png` 即此状态。
- `?view=playlist&player=loading|error&clean=1`：播放器加载与失败/重试状态。删除当前节目会停止播放并选中下一条但不自动播放；清空全部直接执行，不做二次确认。
- `?view=article&ai=processing|success|failed&clean=1`：AI 摘要状态。
- `?view=selected&refresh=error&clean=1`：刷新失败持久反馈、查看详情和逐个重试；按住 Shift 点击刷新也可进入失败。
- `?view=mobile&clean=1`：手机时间线、全页详情返回、菜单抽屉和底部 safe-area toast。
- `?test=long-name`：长订阅源名截断；`?test=99plus`：`99+` 计数；`?test=zero-unread`：零未读/零文件夹计数；`?test=image-fail`：缩略图/封面加载失败占位。

手动验证重点：逐项切换已选文章、空详情、订阅源、普通文章、音频、笔记、搜索和设置，确认左栏无“工具”标题或留白、文件夹仅选中时蓝色加粗，且底部“设置”坐标不变；在展开/收起边栏、抽屉和长订阅树后复测。确认已读来源与标题首字对齐；音频/笔记标题只出现一次、数量紧跟标题、清空与删除都不再弹确认；搜索页无批量已读和排序。文章与播客详情需确认来源和时间戳样式一致，刷新与 Tab 图标视觉重量一致，逐字稿为标准 AudioLines。其余需覆盖时间线筛选、加载 30 天、详情胶囊、刷新失败、音频共享状态、删除与清空等既有流程。

## 范围声明

本原型不接入真实数据、网络、订阅同步、OPML 文件或播放器；交互仅用于表达状态转换和验收路径。预览 PNG 以 1440 × 900 桌面和 390 × 840 手机画板交付，浏览器运行时仍可按断点实时检查。
